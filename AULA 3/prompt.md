# CONTEXT (Contexto)
Muitos gamers passam longas horas jogando e acabam não percebendo a fadiga acumulada, o que afeta o desempenho nos jogos e a saúde física/mental. Para conscientizar os jogadores, queremos criar um modelo preditivo que identifique o nível de cansaço com base no tempo de jogo consecutivo.

# OBJECTIVE (Objetivo)
Desenvolver um script em Python que utilize a biblioteca Scikit-Learn e o algoritmo de Regressão Linear (`LinearRegression`) para treinar um modelo capaz de prever o nível de cansaço do gamer (de 1 a 10) baseado no número de horas jogadas.

Os dados de treino a serem utilizados são:
- Horas de jogo: [1, 2, 4, 6, 8, 10]
- Nível de cansaço: [1, 2, 3, 5, 8, 10]

O programa deve treinar o modelo, realizar uma previsão para um valor de teste (ex: 5 horas de jogo) e exibir o resultado no terminal de forma legível.

# STYLE (Estilo)
Escreva o código em estilo limpo, direto e didático, como um desenvolvedor Python / Cientista de Dados sênior ensinando o passo a passo para um iniciante.

# TONE (Tom)
Educativo, prático e engajador.

# AUDIENCE (Público-Alvo)
Estudantes de programação e iniciantes em Machine Learning que estão aprendendo a implementar regressão linear simples em Python.
